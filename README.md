# 北航博雅课程本地定时选课助手

提前打开程序 → 在学校官方页面登录 → 输入完整课程名或课程 ID → 核对课程和时间 → 输入“确认” → 等待开放时间自动提交。明确成功时显示 **选课成功**；窗口结束、拒绝报名或异常时显示 **抢课失败**，PowerShell 会保留结果，等你自行关闭。

程序面向单个学生、单门“直接选课”课程。不能保证抢到名额。程序默认在官网开放时间首次提交，不提前发送报名请求。代码根据 2026-10-21 官网公开前端逻辑实现；没有使用学生真实账号进行选课验证，学校页面或接口更新后可能需要适配。

## 首次安装（Windows）

需要 Python 3.10 或以上（推荐 3.12）、Microsoft Edge，以及能访问学校选课系统的网络。下载本仓库 ZIP 并解压，或：

```powershell
git clone https://github.com/shrrrrrrrr/bykc.git
cd bykc
```

在解压后的文件夹中打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

`Bypass` 仅针对这次 PowerShell 进程，不修改系统执行策略。安装过程只下载 Python 依赖，默认使用已安装的 Edge。

## 使用示例：17:50 准备，18:00 报名

17:50 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

1. 在自动打开的浏览器中检查地址为学校 HTTPS 域名，输入学号、密码并完成验证码。看到博雅选课系统首页后，回到 PowerShell 按回车。**不要把账号密码输入 PowerShell，也不要发送给开发者。**
2. 输入要选的课程完整名称，或 `ID:12345`。程序从你当前账号可见的本学期课程中检索；同名课会列出课程 ID、教师、校区、上课时间，由你确认具体场次。
3. 提交时间直接回车，采用官网公布的开放时间。如果已开放，回车表示立即开始。也可以填写 `18:00:00`（今天，北京时间）或 `2026-10-21 18:00:00`。早于官网开放时间会拒绝运行；过去的时间不会自动改到明天。
4. 检查课程、首次提交时间及停止时间，输入 `确认`。之后不需要再点报名或确认按钮。
5. 保持 PowerShell 和浏览器运行、电脑联网；不关机、不休眠。程序运行期间会请求 Windows 保持唤醒，但无法抵消关机、合盖策略或断网。可用 `Ctrl+C` 取消。
6. 到点开始自动提交。成功或停止后自动关闭本次临时浏览器，PowerShell 显示结果并等待回车。你也可以直接关闭终端。

也可以事先填写非敏感参数：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\bykc.py --course "完整课程名称" --start "18:00:00"
.\.venv\Scripts\python.exe -X utf8 .\bykc.py --course-id 12345 --duration 60 --interval 0.5
```

**首次建议提前预演**：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\bykc.py --dry-run
```

预演执行真实登录、课程检索、规则检查及时间确认，随后显示“预演完成”并退出，**不提交报名请求**。正式运行须重新登录和确认。

## 定时、重试和结果

- 全部时间按北京时间解释，启动前请在 Windows“日期和时间”中同步系统时钟。程序不将精度只有秒级的 HTTP Date 当作精确校时依据。
- 提前完成登录和课程确认，在开放前约 15 秒做只读预检，随后等待到点提交。临近开放才确认，预检可能占用提交时间，应预留至少 30 秒。
- 复用官方页面的 `ApiService`，由学校原有代码处理会话、加密、参数及服务器规则。在开始时直接发出与官方报名确认按钮一致的请求，不需要临时刷新页面；没有自行破解或替换加密算法。
- 默认重试窗口 60 秒，提交间隔至少 0.5 秒，最多 120 次，始终串行。可以用 `--duration` 调整窗口（1–600 秒）、`--interval` 调整间隔（0.5–30 秒）。无论配置如何，官网选课结束后不再发起新的报名请求。
- 课程已满、暂未开放、明确繁忙等情况在窗口内有限重试；出现访问限制、验证码或资格拒绝则停止，不自动绕过。抽签课程不支持，以免将预报名错误报告为选课成功。
- 只有官方报名接口明确返回成功，或课程列表中该 **课程 ID** 的 `selected` 为 `true`，才显示“选课成功”。不使用模糊文字匹配来认定成功。
- 报名超时或提示重复报名时，停止继续写入，只读核验同一课程。最终结果仍不明确，会显示“抢课失败”并提示去官网核对；**这表示程序未能确认成功，不证明学校服务器一定没有选上**。提交途中取消或断网同样需要核对官网“已选课程”。
- 停止时间是“停止发起新提交”的时间。已发出的请求和最后一次只读核验可能晚于这个时间完成。
- 定时受操作系统调度、网络、服务器时钟、拥堵、会话有效期与余量影响，不能承诺零延迟或必中。程序不提前占位，不并发轰炸，也不退选其他课程。

## 账号和密码保护

程序没有学号/密码参数、密码文件或凭据采集界面；你只在学校官方登录页面输入。使用独立的非持久浏览器上下文，不复用日常浏览器资料，不导出 Cookie、令牌、storage state、HAR、trace、录屏或截图；结束时关闭本次上下文。不向 GitHub 或其他第三方服务上传运行数据，不自动更新代码。

程序只允许本次浏览器访问 `https://buaa.edu.cn` 及其子域，保留 HTTPS 证书验证；学校页面引用的百度地图等第三方资源会被阻止。若未来登录依赖校外验证码服务，可能需要更新域名规则，不能靠关闭证书验证解决。不会绕过验证码、访问限制和学校的资格/额度规则。

终端只打印课程、时间和固定错误说明，不输出原始网络异常、SSO ticket、学生信息或请求内容。检测到 `DEBUG`、`PWDEBUG`、`PW_LOG` 时拒绝运行，避免调试日志暴露敏感信息。不要自行打开 Playwright 跟踪、日志或保存会话。

“不留存”指本项目不主动保存账号密码或导出会话。学校页面本身会在临时会话中使用认证数据；浏览器临时目录、操作系统交换文件、崩溃转储和学校服务器日志不在 Python 程序的绝对控制范围内。请在可信电脑上运行，不共享终端或临时浏览器，不把运行截图、个人信息、浏览器配置文件提交到仓库。

## 常见问题

- **Edge 无法启动**：确认已安装 Edge。可以改用 `--browser chrome`，或安装 Playwright Chromium 后使用 `--browser chromium`：

  ```powershell
  .\.venv\Scripts\python.exe -m playwright install chromium
  .\.venv\Scripts\python.exe -X utf8 .\bykc.py --browser chromium
  ```

- **课程搜不到**：必须完整同名；确认当前账号在官网能看到该课程。程序会读取分页，不限于第一页。也可填写明确的课程 ID。
- **登录失效**：关闭程序重新运行并登录。建议开放前 5–10 分钟运行，避免过早登录导致会话过期；程序会在临近开放时预检。
- **未到时间但官网显示可选**：公开前端会提前一分钟显示可选，服务器是否接受仍由学校决定。本程序按课程数据公布的 `courseSelectStartDate` 提交，不采用提前显示状态。
- **需要校园网/VPN**：先自行连接学校认可的访问方式，再运行本程序。
- **执行失败**：结果窗口故意不输出可能包含 ticket 的原始错误。先检查 Python 版本、依赖、浏览器、网络及学校官网，再运行 `--dry-run`。不要提供账号密码、Cookie 或原始 HAR 作为故障材料。
